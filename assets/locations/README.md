# Location media

Each place has its own folder. Photos use numbered `photo-01.jpg` names, and animated clips use numbered `clip-01.gif` names. TapMap uses the media list configured for each location in `maptap.html`.

Folders:

- `istanbul-turkey/`
- `jurong-camp-1-singapore/`
- `south-horizons-hong-kong/`
- `the-shack-cebu-philippines/`
- `lemon-hotel-shanghai-china/`
- `phuket-thailand/`

HEIC photos and the original MP4/MOV clips are kept locally in each folder's ignored `originals/` directory. The game uses JPGs and looping GIFs; GIFs have no sound. Add story text to the matching location's `blurb` in `maptap.html` when it is ready.
